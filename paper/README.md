# Avance de investigación

[avance.pdf](avance.pdf) tiene dos páginas; [avance.docx](avance.docx) permite editar el texto y las ecuaciones. El archivo expone objetivo, motivación, modificación y FOC inicial.

Referencia: Ide y Talamàs (2025), [Artificial Intelligence in the Knowledge Economy](https://arxiv.org/html/2312.05481v11), §§3 y 6. [Publicación](https://doi.org/10.1086/737233). El artículo original no se redistribuye aquí.

Para modificar el avance, editar Word y exportar a PDF verificando que siga teniendo dos páginas. Los PDF entregados fueron revisados visualmente. El desarrollo más extenso y los límites del avance están en [extensions.md](../extensions.md).
